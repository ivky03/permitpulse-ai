# Stage 5: delivery checkpoint

The end-to-end portfolio version is locally runnable and covered by CI.

## Included

- FastAPI health, metadata, assessment, and decision endpoints
- Streamlit risk/evidence/review interface
- OpenAPI documentation generated by FastAPI
- Dockerfile and two-service Docker Compose configuration
- Make targets for setup, tests, data, training, indexing, API, and UI
- GitHub Actions unit-test workflow
- Optional Gemini summary rewriting with deterministic fallback
- Plain-English project and interview guide

## Verified locally

- 19 unit/integration tests pass.
- A real trained-model assessment paused for review with 82.5% delay risk and 12
  comparables, then resumed to `approved_for_human_follow_up`.
- The deterministic path requires no API key or external LLM call.

## Honest production gaps

This is a strong portfolio application, not a production SaaS deployment. Before real
use, add authentication/authorization, a durable shared LangGraph checkpointer, secrets
management, request/audit logging, model and data drift monitoring, rate limits, a
privacy/security review, and deployment-specific health/readiness checks. Rebuild and
version model/index artifacts through a controlled pipeline instead of mounting local
files manually.
